# MARBLE Project Website

Project webpage for **MARBLE: An Agentic Benchmark for Spatial Reasoning and Visual Abstraction** (NeurIPS 2026, Evaluations and Datasets Track), hosted at [marble-benchmark.github.io](https://marble-benchmark.github.io/).

- **Paper**: [arXiv:2506.22992](https://arxiv.org/pdf/2506.22992)
- **Code**: [github.com/eth-medical-ai-lab/marble](https://github.com/eth-medical-ai-lab/marble)
- **Dataset**: [huggingface.co/datasets/mrble/MARBLE](https://huggingface.co/datasets/mrble/MARBLE)

The previous 2025 website is preserved on the `legacy-2025` branch and tag.

## Local Preview

This is a self-contained static site (plain HTML, CSS, and JavaScript, with no build step):

```bash
python -m http.server 8766 --bind 127.0.0.1
```

Then open `http://127.0.0.1:8766/`.
